# Rally Run

A small Playdate SDK Lua prototype inspired by classic maze-driving chase games.

## Controls

- A from title/game over: start
- D-pad: queue turns
- A: drop smoke
- B: brake
- Crank: steer left/right when undocked

## Build

```sh
pdc source RallyRun.pdx
```

Then open `RallyRun.pdx` in the Playdate Simulator.
